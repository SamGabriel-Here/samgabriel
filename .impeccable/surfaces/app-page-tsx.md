# Home page surface brief

Scope: the single-page portfolio at `/` (app/page.tsx). Mode: Experience (the work leads; the interface recedes).

Audience and job: a technical hiring manager or recruiter, skimming, often on a phone. They must learn who Sam is, see proof of depth, and make contact within one or two screens.

Action: Contact (mailto form with visible email, GitHub and LinkedIn fallbacks). Secondary: open a project's live demo or source.

Proof: eight projects with public source, four live; the only benchmark is nbodyssey's 176× at one million particles on a Tesla T4; NovaSky's 8,900+ stars; PapVision's "not a diagnostic tool" boundary.

Constraints: static export on Vercel only; real NASA/ESA/Webb media only, credited; reduced motion yields a complete static page; WCAG 2.1 AA; phone-first readability.

Memorable moment: the first viewport reads as a real telescope image release with Sam's name as its title.
